博客路の始

发布于 2019-08-23 更新于 2026-09-18 阅读 — 随笔

写博客这件事，我已经想了很久。

大一下学期，当我开始重新认识自己的性格和定位时，就萌生了用博客记录学习经历的想法。只是这个念头一直输给惰性，也输给了我想象中的种种困难。

大二下学期，我在极客时间接触到陈皓老师发起的 ARTS 挑战，花了 199 元购买《左耳听风》专栏，也加入了打卡群。可我又不断拿琐事当借口，一直拖到大三。回头看这几年，真正遗憾的并不是起步晚，而是想了很多，却始终没有开始。

所以，我决定先把博客建起来。

写博客首先是为了记录，其次才是分享。以我现在的水平，谈不上教别人什么，但我仍然怀念高中时给同学讲题的满足感。如果某篇记录恰好能帮到别人，那当然很好；即使没有，它至少也能让未来的我看到自己走过的路。

目前，我准备把博客内容分成三类：ARTS 打卡、头脑风暴和琐碎记事。

  1. ARTS 打卡：这会是博客的主要内容。我在原版 ARTS 的基础上做了一点调整，计划每周更新一次，坚持一年。完成时，应该也到了考研前的冲刺阶段。
    • _Algorithm_：一道 LeetCode 算法题，加一道考研每日一题。
    • _Review_：阅读并分享至少一章课外书籍。
    • _Tip_：记录至少一个技术技巧。
    • _Share_：整理极客时间课程带来的思考。
  2. 头脑风暴：从一个本科生的视角，记录对时事和生活的思考，偶尔也会吐槽几句。
  3. 琐碎记事：记录踩坑、排查和解决问题的过程，也分享一些个人爱好。

现在的博客使用 Hexo 和 GitHub 搭建。以后也许会尝试 Solo 和独立域名，但那是后话。

先写起来，比继续等待一个「准备充分」的时机更重要。
